## Project Description

This project is developed to support teachers in managing IELTS Writing classes and evaluating students' writing performance.

The main purposes of the project are:

1. **Test Management**
   Teachers can create and manage IELTS Writing tests by uploading test questions and related materials.

2. **Student and Class Management**
   Teachers can manage students, organize them into classes, and keep track of their learning information.

3. **IELTS Writing Evaluation and Feedback**
   Teachers can evaluate students' IELTS Writing submissions and provide detailed feedback to help them identify their weaknesses and improve their writing skills.
